# SGED

Sistema de Gerenciamento Escolar Digital

O SGED é uma plataforma moderna para gestão escolar desenvolvida com .NET. O projeto tem como objetivo centralizar a administração de instituições de ensino, oferecendo recursos para gerenciamento de alunos, professores, turmas, disciplinas, notas, frequência, calendário acadêmico e comunicação.

Além das funcionalidades de negócio, o projeto demonstra a aplicação de boas práticas de engenharia de software, arquitetura em camadas, observabilidade, mensageria, testes automatizados e infraestrutura moderna.
